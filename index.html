On se connecte

Le seau partagé garde tes tâches synchronisées sur Mac, iPhone et Android. Le même Bin ID et la même Master Key sur chaque appareil, et tu retrouves la même liste partout.

Créer le seau, 2 min, gratuit, sans CB
  1. Sur jsonbin.io, crée un compte gratuit.
  2. Create Bin, colle {"tasks":[]}, sauve. Le Bin ID est dans l'URL.
  3. Menu API Keys, copie ta Master Key ($2a$...).
  4. Utilise un seau dédié au mémo, différent de celui du running Motocultor.
